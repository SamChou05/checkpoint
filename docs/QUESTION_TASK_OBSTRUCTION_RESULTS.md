# Task-obstruction review retains valid controls but still misses errors

The corrected [ten-case qualification](QUESTION_TASK_OBSTRUCTION_PROTOCOL.md)
completed all 20 model calls. It retained all five supported complete items and
rejected four of the five defective authored items for actual defects. It still
failed the frozen complete criterion: the solver defended the dough's false
premise, and the independent teaching audit accepted butter's misleading main.

Explicit obstruction fields preserve legitimate diagnostic answers, and the
separate teaching veto can reject a question whose solver is wrong. Neither
mechanism establishes the truth of the model's declarations. This selected run
supports broader investigation, not production integration or a release claim.

Of the declared labels, 38/40 choices, 9/10 obstruction records and 9/10 complete
main assessments match the independent expectations. Those are label counts,
not counts of fully sound explanations or estimates of production accuracy.
The six newly constructed controls have the expected labels and full-item
decisions. They remain selected basic controls, not fresh model-generated banks.

The dough solver invents a clause-by-clause reset of first mention: it treats the
same dough as a new referent solely because it appears in the next clause. It
therefore declares no obstruction, supports authored A and refutes diagnostic C.
The independent main audit identifies the actual second-reference problem and
vetoes the item. This demonstrates complementary checks on this case, while
leaving the solver's false-premise rationalization unresolved.

Butter is a more language-dependent teaching defect than the incorrect numerical
and Python outputs. Its later referent and stored key are correct. The main's
opening conflates an unspecified amount in this cooking event with generic
reference to a substance; colloquial wording admits a looser reading. The
frozen source-based assessment treats that distinction as instructional content.
The reviewer paraphrases the opening as merely first mention without addressing
its actual general-reference wording. Record that miss with its caveat rather
than relabeling the control after seeing the result.

Correct labels also carry faulty or unsupported internal reasons. Hotel's C
rejection denies generic use of a definite singular count noun; dough's B
rejection treats its noun's countability too categorically. Spinner's C rejection
adds independence of successive spins, which the one-spin premises do not
establish or need. Plant's supported C repeats a broad node/root claim without
resolving the supplied page's contradictory node-free-rooting statements. The
narrow new-plant answer remains supported. These are verifier reasons, not newly
written learner feedback, but they prevent a fully supported 40/40-reasons claim.

All ten controls remain independently assessed at level 2. The teaching model
assigned 3 to dough and 2 to the other nine. Neither count establishes advanced
difficulty, useful distractor discrimination or learning gains.
