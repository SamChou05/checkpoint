# Prose semantic guidance: frozen four-call result

**Decision: do not promote the candidate prompt.** Both Sonnet 4.6 arms returned two normal, native-valid five-row batches, but the candidate missed the frozen content gates. Independent keyless review found 18 of 20 questions with one literal answer. After inspecting the exact authored keys and explanations, 7 of 10 candidate slots and 6 of 10 baseline slots were usable. The candidate regressed on Python (3/5 versus 4/5), produced an ambiguous English collective-noun item, and stated incomplete Boolean rules as universal rules. It did not reach the required 10/10 candidate usable slots, five per scope, zero targeted defects, or usable coverage.

| Scope | Baseline usable | Candidate usable | Decisive candidate defects |
| --- | ---: | ---: | --- |
| Python Boolean values | 4/5 | 3/5 | Two main explanations omit the all-truthy or all-falsy final-operand fallback. The locally evaluated answers are right, but the general rules taught are false. |
| American English agreement/reference | 2/5 | 4/5 | The jury item needs a unit/member and time-frame premise; its explanation also falsely excludes American notional plural agreement. |
| Total | 6/10 | 7/10 | The per-scope regression and false-rule gates fail. |

This comparison appended a distractor/exception check to the authored-prose prompt and otherwise used the same pinned requests and settings. The candidate English gain cannot offset the Python regression under the frozen plan. The calls generated different questions, so the counts are descriptive; they do not estimate a same-item treatment effect or qualify the full worker. The main code retains its prior prompt.
`candidate-source.patch` preserves the isolated source and test change used by the frozen trial without applying the failed prompt to the main runtime.
The archived harness's 14 tests pass in that isolated candidate checkout. Its source-integrity guard intentionally fails if run against main, because main correctly lacks the failed prompt change; replay requires the pinned candidate source.

The blind reviewers disagreed on five agreement questions. Each has one correct **form** for its literal task, but a wrong inflection can express nearly the same underlying proposition. The locked root adjudication treated these as one-answer questions with weak distractor diversity, not as a second grammatical answer. The stricter sensitivity that rejects all five as meaning-near alternatives still fails the candidate's 10/10 gate. Both reviewers independently rejected the reference-revision item with two defensible repairs and the candidate jury item with missing premises. The exact authored key matched the independent answer on every unambiguous row; key agreement did not repair false teaching.

The baseline also had failures: a Python `or` explanation omitted its no-truthy-operand fallback; an English explanation treated singular *they* as necessarily plural; a collective-noun explanation overexcluded American plural usage; and the reference-revision row offered two defensible answers. The candidate's prompt instruction explicitly requested limiting conditions and exception checks, yet did not prevent the observed false rules. This is evidence against promoting that particular instruction, not evidence that all prompt changes are ineffective.
