# Answer-blind review rubric

Review `worksheet.json` without looking up an answer map or earlier task discussion. Treat the dialogue and the exact choices as the entire question. For each item, independently list every defensible answer label; record `none` or `multiple` when appropriate. Explain what each `I`, `you`, `my`, and `your` refers to, and distinguish a speaker's plan or offer from an action that has already happened.

For each of the six choice pairs, decide whether they express materially different actor, owner, or offerer commitments. Check that each choice is coherent English and a plausible interpretation a learner might select. Rate challenge on the project's 1–5 scale relative to the assigned level 2–3 goal. Assess whether this probes unambiguous pronoun reference rather than a fact outside the dialogue.

Finally, compare the two items for a shared solve procedure or cosmetic repetition. Record whether their single-speaker and speaker-shift mechanisms differ enough to justify both in a bank. Note any wording change needed to remove a second defensible reading, any unintended assertion that an action occurred, and any concern about scaling to a 20-item mixed bank. Lock and timestamp the review before opening any private key.
