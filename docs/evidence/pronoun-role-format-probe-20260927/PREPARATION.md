# Pronoun role-map format probe

This is an offline candidate probe, not an integrated constructor, a qualified model result, or a released question bank. It tests two substantively different reference operations under the existing Standard written English objective: resolving several pronouns within one attributed quotation, and updating the `I`/`your`/`my` reference frame when the speaker changes. The answer choices are concise role maps rather than two-verb blanks or four alternative sentences.

The worksheet is deliberately answer-blind. Intended keys and reasoning are held in a mode-600 private file outside Git. Two independent reviewers should use `RUBRIC.md` and save their answers before key comparison. A passing two-item probe would justify a larger closed-data design and bank diversity experiment, not a production claim. In particular, these two examples alone do not establish enough substantive formats for 20 questions.
