# Prospective semantic release suite — draft for independent review

No provider calls are authorized by this document. The twenty-case
[draft packet](controls-draft.json) must receive independent gold review before
the exact requests, source hashes, rubric and criteria are frozen and the parent
approves dispatch. The prior unit-word experiment and its failed criterion remain
unchanged; this is a new prospective suite.

## What counts as meaningful choice diversity

Compare what each option actually proposes in the dimensions the question asks
the learner to decide: a value, result, statement, action, permitted set, or exact
program/literal outcome. Different wording, equivalent numeric forms, and details
irrelevant to that decision do not create a meaningfully different answer. For
example, two wrong capacities with different irrelevant tank colors still propose
the same capacity. A paraphrased cancellation is still cancellation.

Do not equate answers merely because they are both wrong or both right. Different
quantities, actions, claims, boundary conditions and observable program outcomes
remain distinct. Two true claims about different switches are distinct claims,
and still make a single-answer question defective. A valid item's wrong choices
must offer different task-relevant results or interpretations.

Literal distinctions are legitimate when they affect the requested result.
Examples in this suite include Python string case, an observable negative-index
result, inequality direction and boundary inclusion, and a converted distance's
magnitude in the requested unit. Irrelevant literal variation is not a positive
control merely because the displayed strings differ. This suite deliberately
does not recertify the earlier unit-word question with three minute-valued wrong
options.

Question correctness is separate: preserve zero or multiple supported choices,
and reject disagreement with the authored key. The author key is stored only in
the local scoring packet and never appears in the solver input. Gold includes
every supported choice, all equivalent pairs, an independent eligibility label,
and a short derivation. Nonlisted pairs are expected distinct; nonlisted choices
are expected refuted. These cases are intended to be fully determinable, so an
uncertain judgment is recorded separately and cannot count as a correct decision.

## Frozen trial to prepare after gold review

- Four candidate-native solver calls, five new cases per call: twenty cases,
  eighty correctness rows and 120 unordered pair rows. No baseline calls are
  needed for this qualification stage; the prior baseline evidence is retained.
- Ten currently labeled valid items and ten defective items. Defects include
  equivalent wrong answers, irrelevant detail variation, equivalent correct
  answers, distinct multiple correct answers, no correct offered answer, and
  deliberately wrong authored keys.
- The final two batches each contain five realistic application questions across
  different topics: arithmetic, biology, grammar, shopping/time, fractions,
  programming, conservation of mass, inventory and software permissions.
- Use the archived candidate prompt and native v2 schema initially, preserving
  the exact four-choice contract and six-pair validation. No author key, gold
  relation, defect label, or scoring reason enters the model request.
- Sonnet 4.6, disabled thinking, temperature 0.2, maximum 6,000 output tokens,
  read timeout 75 seconds, one SDK attempt. No retry, repair, replacement call,
  after-output relabeling, or additional stage.
- Stop on transport failure, abnormal completion, truncation, invalid strict
  JSON/schema, exact-choice mismatch, missing/duplicate pair coverage or reason
  length violation. Preserve that failure and all unattempted cases in totals.

Prospective required results: all four calls complete within those limits; every
gold correctness and pair relation agrees; all ten valid controls remain eligible
and all ten defective controls are excluded by the appropriate enforced gates.
Report key disagreement, no/multiple supported choices, duplicate vetoes, uncertain
judgments and structural failures separately. A defective item rejected for the
wrong reason does not count as full semantic success.

This is a bounded fixed-suite qualification, not a proof of arbitrary-subject
accuracy, a psychometric assessment, or a repeated-run stability estimate. Its
questions represent realistic item content, but this phase does not call an
author model or certify author-generation yield. A successful solver candidate
still occupies the existing solver slot in the three-stage pipeline and adds no
provider call to the six-call budget.
