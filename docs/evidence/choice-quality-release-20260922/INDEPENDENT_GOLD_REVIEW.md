# Independent pre-freeze gold review

Reviewed `controls-draft.json` and `RUBRIC_AND_PLAN.md` before provider calls.
The earlier unit-word experiment and its failed prospective criterion are unchanged.

The twenty controls support the proposed labels: ten eligible, ten defective.
Each eligible item has exactly one supported choice and four distinct proposed
answers in the dimensions the stem requests. Different magnitudes in the same
unit, string case, list-index results, inequality boundaries, grammatical roles,
water/salt movements and mass predictions are meaningful distinctions here.

The defective controls cover equivalent wrong capacities despite irrelevant
tank color, paraphrased cancellation, equivalent numerical probabilities and
prices, equivalent times, absent correct answers, deliberately incorrect keys,
and distinct multiple correct claims/actions. Two switch claims and two allowed
report actions remain distinct even when both are supported. The membrane's
no-water-flow option and salt-only option also remain distinct: the latter adds
a prohibited salt-transport prediction, not merely the former's negation of flow.

One pre-freeze clarification requested: `meeting_time_duplicate` should state
that times without a.m./p.m. use a 24-hour clock. This makes the intended
`09:35`/`9:35 a.m.` equivalence explicit without changing any gold label.
No other label or control correction is requested.

The rubric improves on bare string identity by excluding irrelevant variation
while preserving differences that affect the requested answer. It does not
equate options merely because they are all wrong or all right. Preserve the
prospective requirement that every correctness and pair judgment agrees: an
item rejected for the wrong reason is not a full semantic success.

Passing this fixed suite would support bounded integration testing. It would
not establish arbitrary-subject accuracy, model determinism, authoring yield,
or repeated-run reliability. No model calls were made in this review.
