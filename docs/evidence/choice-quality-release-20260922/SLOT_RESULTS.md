# Fixed-slot solver: structural success, semantic qualification failed

All four calls completed with valid native JSON/schema, exact four-choice and
six-pair slots, index coverage, strict local decoding, and normal completion.
All 80 correctness labels matched gold; all ten valid items remained eligible.
However, two pair labels were wrong and one duplicate-choice item was admitted.
The candidate therefore failed the prospectively frozen semantic criteria. No
retries, repairs, replacements or after-output gold changes occurred.

## The two remaining errors

`jacket_discount_duplicate` was correctly rejected for equivalent choices, but
one additional pair comparing `$60` with `$20` was falsely labeled equivalent.
That pair's reason discussed the two separate $20 options instead of the fixed
pair it occupied. The trusted decoder correctly associated the output field with
its actual pair; it did not remap the field from the model's contradictory prose.
Fixed identifiers prevent structural self/duplicate/missing pairs, but cannot
force a model's reason to address the identified options.

`meeting_time_duplicate` was incorrectly admitted. The model correctly described
`09:35` and `9:35 a.m.` as the same time but labeled them distinct, saying the stem
asks about notation. The stem defines how notation is interpreted and asks the
arrival time; it does not ask learners to distinguish written notation. Gold
therefore remains equivalent. This is a semantic false negative, not transport
failure or ambiguity discovered after the run.

The former correctness-label failures in water direction, arrival time and
fractions did not recur in this sample. They remain failures in their original
captures. This candidate changed slot identities, choice ordering, output shape
and reason ordering together; this trial cannot attribute the improvement in
correctness labels to any one change.

## What the implementation now enforces

Native `complete_choice_solver_v3` has four required closed choice objects and six
required closed pair objects. No choice text or pair identities are generated by
the model. The application maps fields to the trusted exact offered strings and
revalidates judgments, reasons, complete coverage and indices. An extra self-pair
like the one that stopped the earlier experiment cannot satisfy this schema.
Semantic truth and useful distractor differences remain model judgments.

Input slot order is a stable hash of the prompt and each exact choice, independent
of incoming option order or authored key. Tests cover every permutation and key
of a four-option item. The older production solver already rotated the sanitizer's
choices; it did not always show the correct choice first. This change removes
residual dependence on the authored key's effect on input ordering. It preserves
literal case, whitespace, Unicode, units and operators. Default/legacy APIs remain
unchanged, and the candidate uses the existing solver stage without extra calls.

An independent agent reviewed the implementation and reran all eighteen pair/slot
tests, finding no mapping or strictness defect. Fifteen native-contract tests also
passed. Structural guarantees do not substitute for the failed semantic criterion.
