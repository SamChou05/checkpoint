# Blind one-rule sentence probe

Read only the keyless worksheet. Select every defensible correct answer and
rate cognitive difficulty from 1–5 using: 1 recognition, 2 one familiar rule,
3 several linked steps, 4 interacting constraints, 5 novel integration. The
target is level 2–3. Rate each of the six choice pairs for a meaningful
subject–verb reasoning distinction, not mere different names or nouns. Note
weak distractors or ambiguity. Do not inspect another review before locking.
This is an offline idea probe, not a production candidate or live qualification.
