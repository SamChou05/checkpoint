# Single-rule full-sentence agreement prototype

This is an offline, answer-blind design probe, not a qualified bank or source change. Each worksheet item presents four complete sentences and asks for the one with correct present-tense agreement. The author keys and rule notes were kept in `/tmp/level2-sentence-selection-prototype-20260927-answer-map*.json`, outside the Git worktree, before each independent review. Reviewers saw only their assigned keyless worksheet and wrote JSON reviews; their reported answers are independent judgments, not the private author map. No model-provider or AWS calls were made.

The strongest version here is [`worksheet-v2.json`](worksheet-v2.json), SHA-256 `6543527b43ac19e0b82799d7a0bd48f3460eaafa5837f52560f40fdfdb7581db`, with [`blind-review-v2.json`](blind-review-v2.json). Q01 tests singular indefinite-pronoun subjects with intervening phrases. Q02 tests agreement with the head noun rather than a noun in an intervening phrase, using both directions of number mismatch. These are single familiar-rule applications, with whole-sentence alternatives about different events rather than the older two-blank ordered pairs.

All three blind reviews found no alternate viable key. The v2 reviewer rated the two items within the requested 2–3 range and found each uses one familiar agreement rule. But Q01 repeats the same singular-subject/plural-verb error in three wrong choices; Q02 repeats one plural-head/singular-verb error pair. The v2 reviewer also found the pair of items repeats the same sentence-selection format and general subject-head solving method. Different sentence events are not enough to establish different diagnostic mechanisms. The v3 review corroborated that limitation despite more varied modifier syntax.

The single-rule constraint sharply limits four-way distractor variety: with one correct choice and three incorrect choices, at least two wrong choices commonly share an error direction unless additional syntactic mechanisms are introduced. Adding several mechanisms would make the item harder and could break the intended level-2, one-rule scope. The prototype therefore shows a way to reach unique-key, level-2 full-sentence questions, **not** a proven way to satisfy strict six-of-six meaningful distinctness or bank-level format diversity. No production adoption is recommended from this evidence alone.
