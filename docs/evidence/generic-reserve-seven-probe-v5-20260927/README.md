Trial 04 returned five policy-7 verified questions but failed blind content review: two returned items asked for expected monetary value with dollar-only choices, and one was below the requested difficulty. The only production change under test is source commit `21cbbb7fdcf50f691655e71f3261cdd27b9eccf6`, which adds a code-owned, narrow expected-money repetition filter after the two verifier batches.

The worker authors seven rows once, sanitizes all seven, and verifies the first four and the remaining one to three sanitized rows in answer-blind solver and authored-teaching reviewer batches. Successful topology is five Converse calls: author7, solver4, reviewer up to4, solver for the remaining batch, reviewer for its surviving rows. Each call has one SDK attempt. The harness records authored, sanitized, verified, diversity-filtered, accepted, and returned source ordinals. It requires the returned five to be the earliest five post-filter accepted originals. Underfill, provider rejection, truncation, deadline, and capture integrity failure are terminal for this trial ID; no retry, fallback, top-up, second job, queue, bank insertion, or deployment runs.

`live_probe.py --draft`, `--preflight`, and `--freeze DRAFT_SHA256` are socket-free. Execution also requires an exact plan and harness review lock, a fresh default-profile AWS identity check for account `239342516379`, and a one-shot capture. The review lock is deliberately absent pending independent review. The later `--launch-precheck` and `--execute PLAN_SHA256` commands are the only AWS paths.
