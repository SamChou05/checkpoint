## Limits and reproducibility

The paired sound/defective payloads deliberately make small defects reviewable, and several reasons explicitly refer to a paired counterpart in the same request. Even when direct supporting calculations are correct, that comparison cue limits inference to this diagnostic setting. The trial supplies no performance result for the supplemental semicolon, equivalent wrong-choice or written-representation controls, no fresh full-worker yield measurement and no universal accuracy claim. Adaptive reasoning used a different compatible output budget and sampling configuration; the comparison does not isolate thinking as a single causal variable.

The gate is narrower than the current writer: it checks already frozen main and per-choice feedback and emits only a reason and verdict. The existing authored-solution route already audits an unchanged author main explanation but intentionally has no per-choice feedback. A new gate on the reviewer-written route would add a fourth model stage; two full passes cannot fit the existing six-call ceiling. These semantics and budget differences remain separate from this component result.
