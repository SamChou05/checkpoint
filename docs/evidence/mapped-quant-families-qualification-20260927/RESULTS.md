The post-lock script revalidated the captured native author JSON against
the frozen contract, reproduced its adapted five-row payload, verified the
source/plan hashes and original-slot provenance, and recompiled **all five
learner fields for each of five items** from trusted numeric specs or

explanations nor per-choice feedback depends on an A–D position label.

Manual semantic review found the explanations and feedback factually
supported. Slot 0 correctly adds 5/6 and 3/5 before multiplying by 3;
its wrong options match the described dropped-numerator/denominator or
wrong-denominator multiplication paths. Slot 1 has the unique domain
solution x = 7 to 4x + 7 = 35; each other offered value fails. Its main
explanation verifies the answer rather than deriving x algebraically, a
pedagogical limit but not a factual error. Slot 2's denominator x + 3 is
positive throughout its explicit domain 5–11; x/(x+3) first reaches
8/11 at x = 8, and the explanation correctly checks every smaller domain
integer. Slots 3–4 use plural and singular head subjects correctly despite
nearby nouns, and their feedback identifies each incorrect verb form
without relying on display order.

Within-batch novelty improved on the prior math pair: the three arithmetic
items now require fraction evaluation, equation solving and a rational
inequality boundary, respectively. Both blind reviewers nevertheless
found the two English agreement items closely parallel: each has two
blanks, a plural-then-singular answer pattern and nearby-noun phrases.
Slot 4 adds a compound and an Every subject, so its rule set differs, but
the visible format repeats. We report that separately from the
prespecified per-item gate. The empty-history live request cannot show
how reliably the code-owned history selector varies future batches; its
finite inventory and replacement behavior have only offline coverage.
