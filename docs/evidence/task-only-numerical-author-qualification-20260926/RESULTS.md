# Task-only numerical author: one-shot pilot passed

The frozen one-job trial returned **5/5 original numerical slots** in 127.684 of 240 seconds with four of six reserved Bedrock Converse calls. All five are compiler-proven policy-8 questions. Two independent answer-blind reviewers selected the captured key for every item and independently marked all 30 choice pairs distinct. The post-lock content audit found all five questions mathematically sound, uniquely answerable, in scope, and difficulty 2 or 3. Exact recompilation reproduced all five learner fields for every return. The predeclared pilot gates of at least 4/5 usable slots and four compiled returns therefore pass. This one sample does not establish a population reliability rate or qualify a production default.

All four calls returned native-valid `end_turn` responses. The capture reports 11,305 input and 10,784 output tokens. Two call slots remained unattempted. The one-shot precheck confirmed the intended AWS account `239342516379`, with 898 seconds of credential life; execution checked the same account and retained sufficient credential life before each signed call. The reviewer confirmed durable reservations and pre-dispatch markers, one SDK attempt per call, exact source and schema pins, the 240-second deadline, no fallback, and no unverified return. Thirty socket-blocked harness tests and 1,373 backend tests passed before dispatch.

The returned set tests fraction addition, subtraction, division, a bounded minimum, and a bounded maximum. Their exact keys and all wrong-choice statements are true after choice rotation. The fraction wrong-choice explanations are mostly generic instead of diagnosing a likely mistake; one true reciprocal preamble is awkward, and one maximum explanation omits an explicit algebra step. The first-pass decimal subtraction veto is a concrete reminder that the model's scope judgment is still fallible: `7.2 - 3.75 = 69/20` fits the frozen fraction-and-decimal objective, but the reviewer set `scope_assignment=true`. The second pass filled the slot without overriding that verdict. The compiler, not the model, supplies each released key and numerical teaching.

The immediately preceding [three-item pilot](../quant-author-batch-size-qualification-20260926/RESULTS.md) used the same numerical assignment, model, batch cap, reasoning setting, budget, and verification route, but its union author schema allowed prose. Both author calls chose prose, yielding 3/5 sound items and **zero compiled**. This task-only candidate changes the versioned native author contract and its prompt, and in this run all six authored rows were typed tasks. The two separate samples are historical comparisons, not a paired causal estimate. The candidate is scoped by exact normalized-goal hash and remains opt-in; no worker default, deployed package, or client minimum has changed. A full multi-topic worker trial and rollout review are still needed before selecting it as the production path.
