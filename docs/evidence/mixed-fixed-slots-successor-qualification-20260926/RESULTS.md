**Decision: failed; do not promote the candidate to main or deploy it.** The [frozen plan](plan.json) (SHA-256 `ab83d05ca603f0a978e9018108bc2e89723ddc198f71cdfb9fa93c46b8cfed5d`) used the original five-slot mixed arithmetic/English request with exact 3:2 allocation, six provider-call slots and a 240-second job deadline. Its [capture](capture.json) (SHA-256 `17c49df0d75cb8aab4cf90bc8816068099cc557b661c719f98ad4c234a0b7831`) records one durable Converse dispatch and **0/5 returned questions**. The first call failed after 0.560 seconds with `ValidationException`; the runtime wrapped it as a configuration error and globally stopped. It made no fallback, retry, replacement, solver or reviewer call. No response or token usage was reported, which does not mean zero tokens were billed.

The [read-only CloudTrail diagnostic](VALIDATION_DIAGNOSTIC.md) recovered the service's exact reason: the compiled native grammar was too large. This identifies Bedrock grammar compilation as the immediate blocker, before the model could attempt the five questions. The rejected schema was 5,519 UTF-8 bytes (SHA-256 `316024552a9f67901c652c33ec73a9e311757e4efadd5a7b66bb97666cc2aebb`), with five required named slots and separate mapped row definitions. Local JSON Schema and SDK-shape validation had passed; those checks did not predict Bedrock's compiled-grammar limit. Neither answer correctness nor distractor quality can be measured in this run.

The [keyless worksheet](blind-worksheet.json) (SHA-256 `9673706406f406a828f9f73004f59ea6163c085229594bdbad5feca9c304bb79`) preserves all five original slots as unavailable. There were no stems, choices, keys or teaching fields for independent blind review. The prespecified 5/5 yield, three compiled arithmetic, two English prose, distinct-choice and teaching gates therefore all fail or remain unobserved; no unavailable slot was credited.

The intended account `239342516379` passed the [metadata-only launch precheck](launch-precheck.json) with one STS identity request and no Bedrock call before the trial. The exact draft digest and frozen plan matched their reviewed hashes. The source candidate and harness passed 1,380 backend tests, 42 offline tests and a 34-test zero-provider preflight. Those tests establish local behavior and bounded dispatch, not acceptance of this native grammar by Bedrock. The candidate remains isolated; the live worker and API were not changed.

The [schema diagnosis](SCHEMA_DIAGNOSTIC.md) compares smaller fixed-slot shapes offline. A new prospective trial would need its own source, freeze, credential precheck, provider-call ceiling and blind content gates. This failed one-shot plan is closed and will not be rerun.
