# Mixed math response-format blind review

`worksheet.json` is a keyless, interleaved 12-item test of the two standalone
math prototypes (`aa3e1d8`, `5b9135a`) against six questions from the
quarantined level-2 bank. It is frozen at SHA-256
`0da3ddc7f43b28e2eb1ee296211999fa7c97045ff3ded9af33ad882e38080517`.
The private source/key map is outside Git at
`/private/tmp/checkpoint-math-format-mixed-blind-20260927/answer-map.json`.
Do not open it before both independent reviews are locked.

Reviewers receive only the keyless worksheet. For each item, select the one
supported choice or record ambiguity, rate difficulty 1–5, and judge all six
unordered choice pairs for meaningful semantic differences. Assess all 66
cross-item pairs for strong repetition of both solving decision and response
format, listing the strong pairs and their reason. Also note any distracting
wording, answer leakage, unsupported worked step, or misleading teaching cue
visible in the choices. Do not inspect constructor code or another review.

This is offline content qualification, not native schema acceptance or a
full-worker trial. Passing one key and distinct choices does not by itself
justify wiring the prototypes into production or claiming 40/80-item variety.
