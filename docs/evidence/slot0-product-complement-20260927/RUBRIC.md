# Blind review rubric

Review each item from its stem and four choices alone. Record findings separately from the worksheet.

- **Correctness:** Independently evaluate the exact expression. Exactly one offered choice must equal its value; flag any missing or multiple correct choices.
- **Choice distinctness:** Compare all six unordered pairs (A–B, A–C, A–D, B–C, B–D, C–D) as exact rational values. Flag equivalent values or options that communicate the same answer.
- **Difficulty:** Judge whether each item fits level 2 or 3 practice; flag an item that is trivial, unexpectedly advanced, or depends on an unstated method.
- **Naturalness:** Check that the wording and notation are self-contained, clear, and natural for a learner.
- **Within-family repetition:** Compare the four items together. Flag items that feel like the same exercise with only numbers changed, and describe any meaningful difference in the decision or calculation required.
