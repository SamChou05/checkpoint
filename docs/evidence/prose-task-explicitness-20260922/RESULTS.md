## What the change did and did not fix

All twenty stems contain an actual revision/replacement instruction. The
candidate specifies the editable span and avoids the baseline's alternative
agreement repairs that change a singular subject into a plural one. However,
its pronoun questions still omit the intended referent while offering multiple
explicit names or objects that all satisfy the stated task:

- Either the coach or captain can replace an ambiguous `they`.
- Either the laptop or concrete floor can replace an ambiguous `it`.
- Either the manager's or intern's name can identify the computer's owner.
- Either Maria or Elena can replace the ambiguous `she`.

The author explanations choose an unstated intention. One invents a preference
for the captain because being addressed before a game would supposedly make that
person more nervous; another calls the laptop a more plausible referent. These
are not premises establishing one correct answer. Supplying an explicit editing
verb did not supply the missing semantic constraint.

The candidate past-sequence explanation also claims that simple past `finished`
would imply simultaneous action. That categorical teaching is too strong: context
can establish event order without requiring past perfect in every case.
[Cambridge's publisher excerpt, Unit 5](https://oxico.sk/lg/aj/assets/ukazky/advanced_grammar.pdf)
explains the relevant qualification. The exact offered task's uniqueness remains
explicitly uncertain in the blind reviews; it is not repaired after seeing the key.

The other candidate tense item explicitly requests simple past, so `finished`
is unambiguously right. Its main contrasts present-perfect current relevance
with a completed past event. Root records a strict misleading-teaching concern
and a contextual upper-bound assessment; the independent reviewer treats this
as contextually qualified imprecision. Present perfect can describe completed
actions, as the [Oxford entry's examples](https://www.oxfordlearnersdictionaries.com/us/definition/english/already)
illustrate. This sensitivity changes the candidate count by one and never its
failed disposition. It must not be conflated with the definite reference failures.

Baseline defects include both valid singular/plural agreement revisions,
equivalent optional-`that` sentences, and `the former` naming the same manager as
another offered revision. Two baseline mains contain unbound Option A/B/C/D
references. Those raw explanations are unsuitable for shuffled learner output;
the existing final-review guard remains necessary. Author-only sanitization is
not final release admission.
