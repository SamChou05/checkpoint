# Generic prose seven-row reserve qualification draft

This is an **inert, socket-free draft**, not a launchable experiment. A concurrent implementation is changing the opt-in generic route. Its source and native author wire are not frozen yet, so reusing an older full-worker harness or dispatching AWS now would not produce a reviewable result. `protocol_guard.py` deliberately has no provider or credential path.

The fixed synthetic request asks for five self-contained probability questions without a skill map, source document, or adaptive plan. The candidate route must make **one native seven-row prose author call**, retain each source ordinal through adaptation and review, and return the **earliest five accepted rows** after all existing sanitizer, answer-blind complete-choice solver, six-pair distinctness, and authored-teaching reviewer gates. No candidate may be hand-picked from the seven after seeing model output. A partial return is a failed job; there is no retry, repair, fallback, top-up, or second job.

Before a live run, create a separate frozen `plan.json` and source-pinned harness in this folder. The plan must record the pushed source commit and exact service-file hashes, this request's byte hash, the seven-row native schema and exact author wire hashes, model/runtime/SDK versions and endpoints, the committed harness hash, a reviewed Bedrock account/profile, and the predeclared gate below. Run a socket-free fake-provider replay that proves seven authored rows, original-ordinal mapping, five-survivor selection, a four-survivor failure, and budget/deadline refusal. Have an independent agent review the exact hashes and wire. Only then do one bounded STS precheck and one live execution. Do not reuse a prior capture or alter this draft's request to fit output.

The future harness should follow the existing [bounded capture helper](../../../backend/bedrock-question-service/evals/bounded_bedrock_capture.py) and [one-shot full-worker example](../combined-v12-selector-first-full-worker-qualification-20260927/full_worker_probe.py): create its capture exclusively before credentials; begin a one-shot 240-second `SIGALRM` **before** execute-time credential export and STS; use at most six durable Converse reservations with one SDK attempt per call, 3-second connect and 200-second read ceilings; perform one signed STS request at precheck and one at execute, on an explicitly checked account and endpoint. Store only redacted visible model text, safe usage/metadata, original seven-row status, and precise rejection codes. Never store credentials, hidden reasoning, raw exceptions, or request headers. A failed/interrupted run is final for this trial ID.

The official machine gate is **five returned rows from seven original authored ordinals**, five unique keys offered exactly once, policy revision 7 on every returned row, backend difficulty at least 2, all 30 within-question choice pairs meaningfully distinct, sound main explanations, and no strong cross-question repeat. The returned order must be the earliest five surviving source ordinals, with missing/rejected ordinals explicit. This gate is evaluated on the actual captured worker output and rejected when evidence is missing. Two independent reviewers then receive only a shuffled, answer-blind worksheet of the returned five: prompt and four choices, without keys, source ordinals, model/reviewer ratings, or rejection reasons. Each reviewer records the selected key, any second defensible choice, all six within-item pair judgments, self-containment, topic fit, difficulty 2–3, and cross-item repetition. After both answer choices are locked, they inspect the main explanation in a separate reveal and record teaching accuracy. Lock both reviews before opening the private returned-key map. Any disagreement about a key or material uncertainty fails qualification pending a **new** experiment; it does not authorize editing this capture.

This one job can establish that the candidate worked for one fixed request under a bounded budget. It cannot establish a population success rate or a causal advantage over five-row authoring without a separately randomized comparison. The current deployed TestFlight path remains legacy and is outside this experiment.

Preparation check: `python -B protocol_guard.py --check-draft`, then `python -B -m unittest -q test_protocol_guard.py`. Both are socket-free. No AWS or Bedrock call is part of this draft.
